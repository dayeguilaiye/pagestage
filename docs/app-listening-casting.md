# App 收听、服务商设置与演员表

App 的界面由 Claude 实现。`lib/application/contracts.dart` 定义页面使用的播放、配置、同意、演员表、生成、音色与存储接口；`AppServices` 在启动时将真实实现接入页面。界面测试使用这些接口的假实现。

## 收听

从书架或章节打开收听时，`ListeningController` 优先读取当前演播模式下有效的已合成音频。缺少音频时询问生成本章或使用系统朗读；建档范围外提供系统朗读，并可转到延伸建档。设置为自动生成后，建档范围内直接进入生成。系统语音按中文或英文选择本地音色，按句生成本地 WAV，再交给同一个音频引擎播放。长句分块保留原文的 UTF-16 区间与完整文字。生成的本地语音缓存在书的音频目录内，删除书时一并清理。

已合成音频沿用台词与停顿共用的 PCM 时间轴。正式播放器把已完成台词及其停顿写入本地播放片段，由 just_audio 原生播放列表连续播放；后续台词完成后追加进列表。正文高亮跟随当前台词；点台词打开操作菜单，选择「从这里播放」后才改变播放位置。正文分段的版本随系统朗读与剧本变化更新，书签同时保存台词和原文位置。

播放器支持播放、暂停、前后句、前后章、0.5–3 倍速、按时长关闭与播完本章关闭。章节播放完成后继续下一章，每本书保存章节、台词和全书进度。系统语音的章节进度按句计算，完整章节时长在逐句合成期间尚未确定。音频中断或耳机断开时暂停。

演播模式按书保存：有声书模式朗读说话提示，广播剧模式跳过说话提示。切换模式时复用有效的台词缓存；目录状态按当前模式计算。

`ListeningHandler` 将通知栏和锁屏命令交给同一个控制器：跳过对应前后句，快进/快退对应前后章，队列索引对应章节。实际系统界面提供的按钮由系统决定。

## 服务商与发送同意

LLM 设置包含 base URL、Chat Completions 或 Responses 协议，以及建档、导演两个模型槽位。导演模型留空时使用建档模型。MiniMax 和百炼各保存独立 key，百炼可选择北京或新加坡区域。

key 保存在 iOS Keychain 和 Android Keystore 支持的安全存储中。普通 SQLite 设置保存地址、协议、模型和区域；页面读取已保存 key 的存在状态。保存时，空缺参数保留 key，空字符串删除 key，其他字符串替换 key。App 通过内存配置快照创建适配器。

每次操作在发送内容前核对目标服务商和实际地址的同意记录。请求同意时展示书名、接收方、地址和内容类型；取消后操作结束。LLM 地址或百炼区域改变后，相应的新目的地重新请求同意。服务商接受的请求沿用 core 的本地用量记录，保存于 App 私有目录的 `usage.jsonl`。

## 建档与演员表

建档由持久化 `Scheduler` 执行，范围按章节选择并可向后延伸。任务按章保存，中断后继续未完成的章节。key、余额或网络问题会暂停任务，并以可本地化的固定错误类别交给界面；更新设置后可以继续。

建档后自动推荐选角，延伸时保留已有音色并补齐新增角色。全局专属音色数量默认 20，修改后重新推荐。演员表提供旁白、角色、身份和临时角色；页面接口只暴露各自的资料，身份与所属角色的关联保留在 core 内。

试听样音保存在书的音频目录内，再次试听复用已保存文件。停止尚未完成的试听会保留生成结果并取消自动播放。正式收听和角色试听共用互斥播放行为。

## 边听边生成

`GenerationController` 将收听意图交给建档共用的持久化 `Scheduler`。选择生成后，第一条可播放台词完成即可出声；播放到已完成部分的末尾时等待后续合成，继续使用合成音频。已进入队列的下一章在到达时提升为用户任务，继续等待或播放。

导演与合成提前量默认分别为 2、1 章，取值为 0–20，合成提前量不超过导演提前量，0 关闭对应提前量。合成音频正在收听时才报告提前量；暂停或转为系统朗读后停止待执行的自动任务。静默阅读只读取本地数据。导演产生的临时角色沿用 core 的章节选角准备流程补齐音色。

服务商请求统一经过 `ProviderGateway`，使用当时的安全配置、按目的地记录的发送同意及共享请求节流队列。服务商失败保留任务与台词缓存，界面显示安全错误类别，用户处理后按书继续。用户拒绝发送同意时不调用相应服务商。

从选择生成到启动原生播放的耗时写入 App 私有目录的 `generation-timing.jsonl`；每条记录只含书 ID、章节、模式、时间和耗时，不包含正文或 key。

## 换音色与音色设计

预设音色按书的语言和百炼区域过滤，可试听后选定。每条台词的缓存键包含其音色绑定；换音色后重新合成时，其他说话人的有效缓存继续复用。手动选择和设计的音色在重新推荐选角时保留。

配置 MiniMax 或百炼北京区后可以按声音描述生成三个候选，候选及样音保存在书内。MiniMax 候选选定时立即合成样音激活绑定，再保存选择。设计中断时已经完成的候选可继续查看。预设试听、候选试听、演员表试听与正式收听相互停止，离开试听页时停止样音。

合成遇到无效音色绑定时按保存的声音描述重建，并重新生成激活样音。任务使用新绑定重算输入哈希，再复用其他台词缓存继续。每个音色在一次恢复过程中只重建一次；恢复仍失败时暂停并报告原因。重建通知持久化到书库，提示重新试听，用户可关闭提示。

## 存储

存储页显示每本书的本地数据量及可清理音频量。数据量按书所属 SQLite 文档的 UTF-8 实际字节数，加上所属音频文件长度计算；SQLite 页、索引和 WAL 的共享开销不分摊到单本书。清理数值是可释放音频文件的实际字节数。

清理前确认。清理时停止播放与试听，让该书正在执行的生成任务保存到检查点，再取消剩余生成任务并删除合成音频、缓存、系统朗读和试听样音。正文、剧本、演员表及音色描述保留；有剧本的章节回到已导演状态，之后收听按生成规则重新准备。其他书仍引用的共享缓存、用户原始导入文件和外部导出文件保留。
