# 首版没有自己的服务器：BYOK，客户端直连服务商

首版不运营任何服务端。用户在 App 里填入自己的 LLM 和 TTS key（BYOK），App 从设备直接调用各家服务商的 API，书的正文和生成的音频只在设备和用户选定的服务商之间流动。这样项目没有运维成本，也不必替用户垫付模型费用，开源版本可以独立运行。将来如果提供付费的托管服务，它在 App 里只是又一家服务商，不改变这条架构。

## Consequences

- key 只保存在设备的安全存储里，不经过我们的任何服务器。
- 将来如果要做 Web 版，得先解决浏览器跨域调用的问题：不少服务商不允许浏览器直接调用。
- 不接入任何第三方统计或崩溃上报 SDK，也不自动上报。App 在本地记录崩溃和错误日志（不含 key 和书的正文），用户可以一键导出，自己附到 GitHub Issue 上反馈问题。
