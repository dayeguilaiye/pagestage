# 剧本由 LLM 分段，并带上原文

导演时，由 LLM 直接写出剧本：它自己决定怎么划分台词，每条台词都带上对应的原文，再附上表演指令。我们考虑过另一种做法：先用规则把章节切成带编号的片段，LLM 只回传编号和表演指令。那样输出更省，原文也不可能被改动；但规则在多种语言、不规范的引号、不带引号的心理活动这些情况下容易切错，而且 LLM 只对着编号标注时容易错位。带上原文，LLM 不容易走偏，也能更聪明地分段。

## Consequences

- 导演的输出大约要多出一章正文的 token，成本相应上升；不过全书成本的大头仍然是 TTS。
- LLM 写出的原文可能和书里有出入，所以导演完成后要把每条台词对齐回原文。朗读和高亮用的永远是对齐后的原文，LLM 写出的文本只用来定位。
- 对不上时先重新导演，次数有限。仍然没被覆盖的原文交给旁白念，在原文里找不到的台词直接丢弃。整个过程对用户不可见：这是面向普通听众的产品，不给用户留「待检查」之类的任务。
