# 音色以声音描述为准，服务商的音色只是绑定

一个音色保存的是一段自然语言的声音描述，加上试音时选定的样音。它在某家 TTS 服务商上的具体实现，比如预设音色、设计出的音色或克隆出的音色，只是一个可以随时重建的音色绑定。原因是服务商变化太快：OpenAI 的 TTS 模型将在 2027-01-06 下线；MiniMax 设计出的音色，7 天内不用来合成就会过期；Gemini 设计的音色只有一年有效期。用户在选角和试音上花的功夫，不能被某一家服务商锁死。

## Consequences

- 换服务商时按声音描述重新选角。支持克隆的服务商，可以用样音把同一个声音迁移过去；样音本身是合成的，不涉及真人。
- 重建出来的声音不会和原来完全一样，需要用户重新试听确认。
